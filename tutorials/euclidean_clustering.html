Tutorial 1 — Euclidean clustering

Capability 1: produce clusters for a climate + soil input. In this tutorial you build a synthetic climate + soil grid, derive a per-cell feature matrix, and group the cells into K clusters with plain Euclidean clustering — the simplest mode, needing no supervision and only the core install.

Load data and build a feature matrix

The shared helper writes synthetic NetCDFs and loads them through the real data entry point, returning a DataRegistry and a feature matrix X of shape (n_valid_cells, n_features):

from _synthetic import feature_matrix, load_synthetic

_paths, datasets, registry = load_synthetic(tmp, n_cells=64)
X, meta = feature_matrix(datasets, registry)   # X: (64, 8); meta: cell_id/lat/lon

Cluster

cluster_matrix() with locally_weighted=False runs agglomerative clustering. standardize=True z-scores each feature first so no single feature dominates:

from climclusterpy import cluster_matrix

result = cluster_matrix(X, n_clusters=6, locally_weighted=False, standardize=True)
result.labels           # 1-indexed label per cell, shape (64,)
result.to_frame()       # cell_id + cluster_label

The result carries the SciPy linkage matrix (so you can re-cut to a different K without re-clustering) and, when you pass a DataFrame, the metadata columns.

The complete script

examples/example_1_cluster_euclidean.py
#!/usr/bin/env python3
"""Capability 1 — produce clusters for a climate + soil input (Euclidean mode).

Runs entirely on tiny synthetic data with only the lightweight core dependencies.

    python examples/example_1_cluster_euclidean.py
"""

from __future__ import annotations

import tempfile

import numpy as np
from _synthetic import feature_matrix, load_synthetic

from climclusterpy import cluster_matrix


def main() -> None:
    with tempfile.TemporaryDirectory(prefix="climclu_ex1_") as tmp:
        # Real data entry point: build synthetic climate+soil NetCDFs, load them,
        # and derive a per-valid-cell feature matrix.
        _paths, datasets, registry = load_synthetic(tmp, n_cells=64)
        X, meta = feature_matrix(datasets, registry)
        print(f"Feature matrix: {X.shape[0]} cells x {X.shape[1]} features")

        # Cluster in plain Euclidean mode (agglomerative, complete linkage).
        result = cluster_matrix(X, n_clusters=6, locally_weighted=False, standardize=True)

        labels, counts = np.unique(result.labels, return_counts=True)
        print(f"Euclidean clustering -> {result.n_clusters} clusters (mode={result.mode})")
        print("Cluster sizes:", dict(zip(labels.tolist(), counts.tolist())))
        print("Result frame columns:", list(result.to_frame().columns))
        assert result.labels.shape[0] == X.shape[0]
        assert set(result.labels.tolist()) <= set(range(1, 7))
        print("OK: example 1 (Euclidean clustering) complete.")


if __name__ == "__main__":
    main()
