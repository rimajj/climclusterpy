Tutorial 0: the whole workflow in two calls

This tutorial reduces a climate grid to K groups, takes the output of a (synthetic) model run on the reduced grid and rebuilds the original grid from it. It needs two function calls and the base install only.

Running a land-surface model on a full global grid is expensive. When you group cells by similarity, you need to run the model on only one cell per group, or a few (see Choose the simulated cells), and every original cell then receives the output simulated for its group. climclusterpy provides the two ends of this workflow:

from climclusterpy import create_clusters, reconstruct_original_grid

clusters = create_clusters(
    climate={"temperature": "/data/tas.nc", "precipitation": "/data/pr.nc"},
    static={"soil": ("/data/soil.nc", "categorical")},
    n_clusters=2000,
)
# ... run your model on clusters.netcdf_files ...
full = reconstruct_original_grid("vegc_output.nc", clusters=clusters)

Build the reduced grid

create_clusters() takes the climate fields by name (climate=, each a NetCDF with a time axis) and any static fields (static=, each declared categorical or continuous). Prepare the input files lists the other ways to describe the input. The function then:

  1. loads the input and builds the registry of valid cells;

  2. summarizes each cell into ecological features (annual means, seasonality, Köppen diagnostics, the static fields), then standardizes, de-correlates and PCA-filters them;

  3. clusters the cells;

  4. selects the cells to simulate in each group;

  5. writes the reduced-grid NetCDFs and the two mapping CSVs that record which original cells each reduced cell stands for.

clusters = create_clusters(
    climate={
        "temperature": files.temperature,
        "precipitation": files.precipitation,
        "short_wave_radiation": files.short_wave_radiation,
    },
    static={"soil_depth": (files.soil_depth, "continuous")},
    n_clusters=6,
    output_dir="./clusters",
)
clusters.cluster_files      # the NetCDFs your model reads
clusters.labels             # cell_id, latitude, longitude, cluster_label
clusters.id_mapping_csv     # reduced cell -> original cells
clusters.compact_map_csv    # row map for correct lon slicing at large K

Learned distance

The Euclidean distance weights all features equally. With locally_weighted=True, the package first learns a distance, so that the directions in feature space that separate ecologically different cells count for more. This needs the [lmnn] extra:

clusters = create_clusters(
    climate={"temperature": "/data/tas.nc", "precipitation": "/data/pr.nc"},
    n_clusters=2000,
    locally_weighted=True,
    supervision_data="/data/model_output/trait_grids",   # or a per-cell CSV
    supervision=["sla", "wooddens", "height", "biomass"],
)

supervision_data can be a directory of per-trait NetCDFs or a prepared per-cell CSV, and the package detects the form automatically. Without supervision_data, the package computes Köppen–Geiger classes from the climate input, so the learned distance needs no extra data.

With a learned metric, the cell simulated for each group defaults to its medoid (the member with the smallest total distance to the others, measured in that metric) instead of the member nearest the cluster mean.

Rebuild the original grid

reconstruct_original_grid() takes the model output and the clusters object, which holds the registry and both mapping CSVs:

full = reconstruct_original_grid("vegc_run.nc", clusters=clusters)
full.path      # the reconstructed NetCDF
full.files     # {source: reconstructed} for every input

It accepts a single file, a list or a directory of model output. It matches cells by group label, not by coordinate, and cells outside the valid mask stay NaN. Checking a reconstruction describes how the package checks the result.

The script

examples/example_0_one_call_roundtrip.py
#!/usr/bin/env python3
"""The whole package in two calls: reduce a grid, then rebuild it.

This is the example to read first. ``create_clusters`` takes the climate (and any
static fields such as soil) as NetCDF files, named however your model names them, and
writes a *reduced* grid — one cell per cluster — that a vegetation model can run on
directly, plus the mapping CSVs that record which original cells each reduced cell
stands for. ``reconstruct_original_grid`` uses
those mappings to put simulated output back onto the full grid.

Runs on tiny synthetic data with only the lightweight core dependencies::

    python examples/example_0_one_call_roundtrip.py
"""

from __future__ import annotations

import os
import tempfile

import numpy as np
import xarray as xr
from _synthetic import write_synthetic_inputs

from climclusterpy import create_clusters, reconstruct_original_grid


def simulate_model_run(clusters, path: str) -> str:
    """Stand in for the vegetation model.

    A real run would read the cluster NetCDFs, simulate, and write its own output on
    that same reduced grid. Here we just give every cluster a recognisable value so
    the round trip can be checked exactly.
    """
    with xr.open_dataset(clusters.netcdf_files["temperature"]) as ds:
        label_grid = ds["cluster_label"].load()

    values = np.full(label_grid.shape, np.nan, dtype="float32")
    finite = np.isfinite(label_grid.values) & (label_grid.values >= 0)  # -1 = no cluster
    values[finite] = label_grid.values[finite] * 100.0

    xr.Dataset(
        {"vegc": (("time", "lat", "lon"), values[None, ...])},
        coords={
            "time": [0],
            "lat": label_grid["latitude"].values,
            "lon": label_grid["longitude"].values,
        },
    ).to_netcdf(path)
    return path


def main() -> None:
    with tempfile.TemporaryDirectory(prefix="climclu_ex0_") as tmp:
        input_dir = os.path.join(tmp, "climate_input")
        files = write_synthetic_inputs(input_dir, nlat=8, nlon=8, nmonths=24)

        # --- Call 1: grid in, model-ready cluster grid out ------------------------
        # For a metric learned from your model's own output instead of plain
        # Euclidean distance, add:
        #     locally_weighted=True,
        #     supervision_data="/path/to/trait_netcdfs_or_table.csv",
        #     supervision=["sla", "wooddens", "height", "biomass"],
        #
        # The input: climate fields by name (a field recognised as temperature,
        # precipitation, radiation or humidity gets its own features and unit handling;
        # any other name is summarised generically) and static fields declared
        # categorical or continuous. Every cell where all fields have data is clustered;
        # pass land_mask= or grid= to choose the cells instead. The same input can be
        # built first as GenericInputs(climate=..., static=...) and passed in its place.
        clusters = create_clusters(
            climate={
                "temperature": files.temperature,
                "precipitation": files.precipitation,
                "short_wave_radiation": files.short_wave_radiation,
            },
            static={"soil_depth": (files.soil_depth, "continuous")},
            n_clusters=6,
            output_dir=os.path.join(tmp, "clusters"),
            min_grid_spacing=0.5,  # the synthetic grid is 0.5°
            n_jobs=1,
        )
        print(
            f"create_clusters -> {clusters.n_clusters} clusters "
            f"({clusters.mode} mode, {clusters.cell_selection} cell selection)"
        )
        print(f"  {len(clusters.cluster_files)} cluster NetCDFs in {clusters.output_dir}")
        print(f"  labels for {len(clusters.labels)} original cells -> {clusters.labels_csv}")
        print(f"  id mapping:  {os.path.basename(clusters.id_mapping_csv)}")
        print(f"  compact map: {os.path.basename(clusters.compact_map_csv)}")

        # --- The vegetation model runs on the reduced grid ------------------------
        model_output = simulate_model_run(clusters, os.path.join(tmp, "vegc_run.nc"))

        # --- Call 2: reduced-grid output in, full-resolution field out ------------
        full = reconstruct_original_grid(model_output, clusters=clusters)
        print(f"reconstruct_original_grid -> {full.path}")

        # Check the promise: every original cell carries its own cluster's value.
        with xr.open_dataset(full.path) as ds:
            grid = ds["vegc"].isel(time=0).load()
        mask = clusters.registry.get_valid_mask()
        labels = clusters.labels["cluster_label"].to_numpy()
        for k, (i, j) in enumerate(np.argwhere(mask)):
            assert np.isclose(grid.values[i, j], labels[k] * 100.0)
        print(f"OK: all {mask.sum()} original cells recovered their cluster's value.")


if __name__ == "__main__":
    main()
