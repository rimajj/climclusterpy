Tutorial 0 — the whole workflow in two calls

Start here. This tutorial does the entire job: reduce a climate grid to K clusters, run a (simulated) vegetation model on the reduced grid, and rebuild the original resolution from its output. Two function calls, core install only.

The idea

Running a land-surface model on a full global grid is expensive. If cells that behave alike are grouped, the model only has to run once per group — on an artificial grid with one cell per cluster — and the full-resolution field can be reconstructed afterwards by giving every original cell its cluster’s value.

climclusterpy does the two ends of that:

from climclusterpy import create_clusters, reconstruct_original_grid

clusters = create_clusters("/data/climate_input", n_clusters=2000)
# ... run your model on clusters.netcdf_files ...
full = reconstruct_original_grid("vegc_output.nc", clusters=clusters)

Call 1 — build the reduced grid

create_clusters() takes a directory holding one NetCDF per input (temperature.nc, precipitation.nc, short_wave_radiation.nc, long_wave_radiation.nc, soil_code.nc, soil_depth.nc) — or a DataPaths, or a mapping — and does everything in between:

  1. load the input and build the valid-cell registry;

  2. summarize each cell into ecological features (annual means, seasonality, Köppen diagnostics, soil), then standardize, de-correlate, and PCA-filter them;

  3. cluster the cells;

  4. pick the cell that best represents each cluster;

  5. write the reduced-grid NetCDFs plus the two mapping CSVs that record which original cells each reduced cell stands for.

clusters = create_clusters(
    input_dir,
    n_clusters=6,
    output_dir="./clusters",
)
clusters.cluster_files      # the NetCDFs your model reads
clusters.labels             # cell_id, latitude, longitude, cluster_label
clusters.id_mapping_csv     # reduced cell -> original cells
clusters.compact_map_csv    # row map for correct lon slicing at large K

Supervised (locally-weighted) mode

Plain Euclidean distance treats every feature as equally important. Pass locally_weighted=True to learn a distance metric first, so directions in feature space that separate ecologically different cells count for more (needs the [lmnn] extra):

clusters = create_clusters(
    input_dir,
    n_clusters=2000,
    locally_weighted=True,
    supervision_data="/data/model_output/trait_grids",   # or a per-cell CSV
    supervision=["sla", "wooddens", "height", "biomass"],
)

supervision_data may be a directory of per-trait NetCDFs or a prepared per-cell CSV — the form is detected automatically. Supervising on your model’s own output traits is the strongest signal available: it groups cells by the very quantity the reduced grid has to reproduce. Omit supervision_data and Köppen–Geiger classes are derived from the climate input instead, so the supervised mode needs no extra data at all.

With a learned metric available, each cluster’s representative defaults to its medoid (the member with the smallest total distance to the others, measured in that metric) rather than the member nearest the cluster mean.

Call 2 — rebuild the original grid

reconstruct_original_grid() takes the model output and the clusters object — which already carries the registry and both mapping CSVs, so no file paths need juggling:

full = reconstruct_original_grid("vegc_run.nc", clusters=clusters)
full.path      # the reconstructed NetCDF
full.files     # {source: reconstructed} for every input

It accepts a single file, a list, or a whole directory of model output. Cells are placed by ID, never by coordinate matching, so the round trip stays exact even when the reduced grid reorders or drops cells; cells outside the valid mask stay NaN.

The complete script

examples/example_0_one_call_roundtrip.py
#!/usr/bin/env python3
"""The whole package in two calls: reduce a grid, then rebuild it.

This is the example to read first. ``create_clusters`` takes a directory of climate
and soil NetCDFs and writes a *reduced* grid — one cell per cluster — that a
vegetation model can run on directly, plus the mapping CSVs that record which
original cells each reduced cell stands for. ``reconstruct_original_grid`` uses
those mappings to put simulated output back onto the full grid.

Runs on tiny synthetic data with only the lightweight core dependencies::

    python examples/example_0_one_call_roundtrip.py
"""

from __future__ import annotations

import os
import tempfile

import numpy as np
import xarray as xr
from _synthetic import write_synthetic_inputs

from climclusterpy import create_clusters, reconstruct_original_grid


def simulate_model_run(clusters, path: str) -> str:
    """Stand in for the vegetation model.

    A real run would read the cluster NetCDFs, simulate, and write its own output on
    that same reduced grid. Here we just give every cluster a recognisable value so
    the round trip can be checked exactly.
    """
    with xr.open_dataset(clusters.netcdf_files["temperature"]) as ds:
        label_grid = ds["cluster_label"].load()

    values = np.full(label_grid.shape, np.nan, dtype="float32")
    finite = np.isfinite(label_grid.values) & (label_grid.values >= 0)  # -1 = no cluster
    values[finite] = label_grid.values[finite] * 100.0

    xr.Dataset(
        {"vegc": (("time", "lat", "lon"), values[None, ...])},
        coords={
            "time": [0],
            "lat": label_grid["latitude"].values,
            "lon": label_grid["longitude"].values,
        },
    ).to_netcdf(path)
    return path


def main() -> None:
    with tempfile.TemporaryDirectory(prefix="climclu_ex0_") as tmp:
        input_dir = os.path.join(tmp, "climate_input")
        write_synthetic_inputs(input_dir, nlat=8, nlon=8, nmonths=24)

        # --- Call 1: grid in, model-ready cluster grid out ------------------------
        # For a metric learned from your model's own output instead of plain
        # Euclidean distance, add:
        #     locally_weighted=True,
        #     supervision_data="/path/to/trait_netcdfs_or_table.csv",
        #     supervision=["sla", "wooddens", "height", "biomass"],
        clusters = create_clusters(
            input_dir,
            n_clusters=6,
            output_dir=os.path.join(tmp, "clusters"),
            min_grid_spacing=0.5,  # the synthetic grid is 0.5°
            n_jobs=1,
        )
        print(
            f"create_clusters -> {clusters.n_clusters} clusters "
            f"({clusters.mode} mode, {clusters.representative} representative)"
        )
        print(f"  {len(clusters.cluster_files)} cluster NetCDFs in {clusters.output_dir}")
        print(f"  labels for {len(clusters.labels)} original cells -> {clusters.labels_csv}")
        print(f"  id mapping:  {os.path.basename(clusters.id_mapping_csv)}")
        print(f"  compact map: {os.path.basename(clusters.compact_map_csv)}")

        # --- The vegetation model runs on the reduced grid ------------------------
        model_output = simulate_model_run(clusters, os.path.join(tmp, "vegc_run.nc"))

        # --- Call 2: reduced-grid output in, full-resolution field out ------------
        full = reconstruct_original_grid(model_output, clusters=clusters)
        print(f"reconstruct_original_grid -> {full.path}")

        # Check the promise: every original cell carries its own cluster's value.
        with xr.open_dataset(full.path) as ds:
            grid = ds["vegc"].isel(time=0).load()
        mask = clusters.registry.get_valid_mask()
        labels = clusters.labels["cluster_label"].to_numpy()
        for k, (i, j) in enumerate(np.argwhere(mask)):
            assert np.isclose(grid.values[i, j], labels[k] * 100.0)
        print(f"OK: all {mask.sum()} original cells recovered their cluster's value.")


if __name__ == "__main__":
    main()
