Tutorial 2: LMNN metric-learning clustering

This tutorial clusters the same synthetic grid with locally_weighted=True. The package learns a distance from a supervision signal before clustering, so that cells of the same supervision class are grouped together. It needs PyTorch (pip install climclusterpy, or pip install 'climclusterpy-base[lmnn]'); without it the script prints an install hint and exits.

Provide a supervision signal

LMNN needs a per-cell class label aligned row by row with the features. For real data, the label comes from compute_supervision() (see Tutorial 3: supervision signals). Here, the example derives three latitude bands from the cell metadata:

import numpy as np

lat = meta["latitude"].to_numpy()
y = np.digitize(lat, np.quantile(lat, [1 / 3, 2 / 3]))   # 0/1/2, aligned to X rows

Learn a metric and cluster

With locally_weighted=True and the supervision labels, the package learns a distance and then clusters under it. This example uses the global (linear) Mahalanobis metric, which is the quickest to train:

from climclusterpy import cluster_matrix

result = cluster_matrix(
    X, n_clusters=6, locally_weighted=True,
    supervision=y, standardize=True, lmnn_mode="global",
)
result.diagnostics       # LMNN training info

Without lmnn_mode, the package uses the default "lowrank": a low-rank metric for every cell, as in the paper. "diagonal" is the same trainer with a diagonal per-cell metric; see Methods.

The script

examples/example_2_cluster_lmnn.py
#!/usr/bin/env python3
"""Capability 2 — choose the clustering mode: locally-weighted LMNN metric learning.

LMNN clustering learns a supervised distance metric before clustering. It needs the
``[lmnn]`` extra (``torch``, for every metric-learning mode).
If that extra is not installed this example prints an install hint and exits cleanly.

    pip install 'climclusterpy[lmnn]'
    python examples/example_2_cluster_lmnn.py
"""

from __future__ import annotations

import sys
import tempfile

import numpy as np
from _synthetic import feature_matrix, load_synthetic

from climclusterpy import cluster_matrix


def main() -> None:
    try:
        import torch  # noqa: F401
    except ImportError:
        print("torch not installed; install the [lmnn] extra to run LMNN clustering:")
        print("    pip install 'climclusterpy[lmnn]'")
        sys.exit(0)

    with tempfile.TemporaryDirectory(prefix="climclu_ex2_") as tmp:
        _paths, datasets, registry = load_synthetic(tmp, n_cells=64)
        X, meta = feature_matrix(datasets, registry)

        # Supervision drives the metric. In practice this comes from
        # compute_supervision(...) (see example 3); here we use three latitude bands
        # so the example needs no extra data and stays perfectly aligned with X.
        lat = meta["latitude"].to_numpy()
        y = np.digitize(lat, np.quantile(lat, [1 / 3, 2 / 3]))  # 0/1/2, aligned to X rows
        print(f"Supervision: {len(np.unique(y))} classes over {X.shape[0]} cells")

        # Global LMNN learns a linear metric; clustering then runs on the transformed
        # features with ordinary Euclidean linkage.
        result = cluster_matrix(
            X,
            n_clusters=6,
            locally_weighted=True,
            supervision=y,
            standardize=True,
            lmnn_mode="global",
        )

        uniq, counts = np.unique(result.labels, return_counts=True)
        print(f"LMNN clustering -> {result.n_clusters} clusters (mode={result.mode})")
        print("Cluster sizes:", dict(zip(uniq.tolist(), counts.tolist())))
        assert result.labels.shape[0] == X.shape[0]
        print("OK: example 2 (LMNN clustering) complete.")


if __name__ == "__main__":
    main()

Run it

$ pip install climclusterpy
$ python examples/example_2_cluster_lmnn.py
Supervision: 3 classes over 64 cells
LMNN clustering -> 6 clusters (mode=lmnn)
...
OK: example 2 (LMNN clustering) complete.
