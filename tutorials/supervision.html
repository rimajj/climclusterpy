Tutorial 3 — Supervision signals

Capability 3: provide the LMNN supervision signal. compute_supervision() builds the per-cell class labels LMNN learns from. This tutorial demonstrates the two sources that run on lightweight synthetic data — Köppen–Geiger (from climate) and model-output (from traits); the ecoregions source is outlined at the end (it needs a shapefile and the [ecoregions] extra).

Köppen–Geiger from monthly climatology

Köppen–Geiger classes are computed from a monthly-climatology feature table — 12 monthly temperature (°C) and precipitation (mm/month) columns per cell, plus cell_id / latitude / longitude. The helper builds that table from the synthetic series:

from climclusterpy import compute_supervision
from _synthetic import monthly_climatology_df

kg_features = monthly_climatology_df(datasets, registry)
kg = compute_supervision("koppen_geiger", features_df=kg_features, output_dir=tmp)
kg.n_classes            # number of KG classes present
kg.encoded_y            # 0..n_classes-1 labels, aligned to the cells

Model-output (trait) clustering

Given a table of simulated traits per cell, kind="output" clusters cells by trait similarity. Provide the trait columns via continuous_cols and the parallel coordinate arrays:

out = compute_supervision(
    "output",
    features_df=traits,
    cell_ids=traits["cell_id"].to_numpy(),
    latitudes=traits["latitude"].to_numpy(),
    longitudes=traits["longitude"].to_numpy(),
    continuous_cols=["vegc", "height", "sla"],
    n_clusters=5,
    output_dir=tmp,
)

Each call returns a SupervisionResult — .labels (the canonical cell_id/latitude/longitude/cluster_label table), .labels_csv (the CSV on disk), and .y / .encoded_y to feed cluster_matrix().

The complete script

examples/example_3_supervision.py
#!/usr/bin/env python3
"""Capability 3 — build the LMNN supervision signal.

Supervision labels can come from climate (Köppen–Geiger), a user shapefile
(Ecoregions2017), or model-output traits. This example demonstrates the two that
run on lightweight synthetic data (Köppen–Geiger and model-output); the ecoregion
path is described at the end (it needs a shapefile and the ``[ecoregions]`` extra).

    python examples/example_3_supervision.py
"""

from __future__ import annotations

import tempfile

import numpy as np
import pandas as pd
from _synthetic import load_synthetic, monthly_climatology_df

from climclusterpy import compute_supervision


def main() -> None:
    with tempfile.TemporaryDirectory(prefix="climclu_ex3_") as tmp:
        _paths, datasets, registry = load_synthetic(tmp, n_cells=64)

        # --- Köppen–Geiger supervision (computed from monthly climatology) ---------
        kg_features = monthly_climatology_df(datasets, registry)
        kg = compute_supervision("koppen_geiger", features_df=kg_features, output_dir=tmp)
        print(f"Köppen–Geiger: {kg.n_classes} class(es) over {len(kg.labels)} cells")
        print("  labels CSV:", kg.labels_csv)
        print("  example encoded labels:", np.unique(kg.encoded_y).tolist())

        # --- Model-output (trait) supervision --------------------------------------
        # Synthetic per-cell traits standing in for LPJmL output (VegC, Height, ...).
        lats, lons = registry.get_valid_lat_lon()
        n = len(lats)
        rng = np.random.default_rng(1)
        traits = pd.DataFrame(
            {
                "cell_id": np.asarray(registry.get_valid_original_ids()),
                "latitude": np.asarray(lats),
                "longitude": np.asarray(lons),
                "vegc": np.asarray(lats) * 0.5 + rng.normal(0, 0.3, n),
                "height": np.asarray(lons) * 0.2 + rng.normal(0, 0.2, n),
                "sla": rng.normal(10, 1, n),
            }
        )
        out = compute_supervision(
            "output",
            features_df=traits,
            cell_ids=traits["cell_id"].to_numpy(),
            latitudes=traits["latitude"].to_numpy(),
            longitudes=traits["longitude"].to_numpy(),
            continuous_cols=["vegc", "height", "sla"],
            n_clusters=5,
            output_dir=tmp,
        )
        print(f"Model-output: {out.n_classes} classes over {len(out.labels)} cells")
        print("  labels CSV:", out.labels_csv)

        # --- Ecoregion supervision (needs a shapefile + the [ecoregions] extra) -----
        print(
            "Ecoregion supervision: compute_supervision('ecoregions', registry=registry, "
            "ecoregions_shapefile='Ecoregions2017.shp') — requires geopandas and a shapefile, "
            "so it is not run in this synthetic example."
        )

        assert kg.n_classes >= 1
        assert out.n_classes >= 1
        print("OK: example 3 (supervision signals) complete.")


if __name__ == "__main__":
    main()

Ecoregion supervision

The third source assigns cells to WWF Ecoregions2017 polygons by spatial join. It needs the [ecoregions] extra and a shapefile, so it is not exercised on synthetic data:

sup = compute_supervision(
    "ecoregions",
    registry=registry,
    ecoregions_shapefile="Ecoregions2017/Ecoregions2017.shp",
)

See Build an LMNN supervision signal for details and Tutorial 2 — LMNN metric-learning clustering to use the signal.
