Clustering & metric learning

The clustering primitives the cluster_matrix() facade is built on. Prefer the facades for ordinary use; these are exposed for finer control. The supervision-label generators live in Supervision labels.

LMNN metric learning

Note

Every LMNN mode needs torch, through the [lmnn] extra. See Install climclusterpy. Importing climclusterpy.clustering.lmnn does not import it; a mode loads it when it trains.

run_lmnn_clustering(X, labels, n_clusters, *, mode='global', linkage_method='complete', rank=None, k=None, seed=None, verbose=False, return_distance_matrix=False, return_model=False, **lmnn_kwargs)[source]

Learn an LMNN metric from supervision labels, then hierarchically cluster.

This is the in-memory, path-free core of the LMNN clustering pipeline. It

  1. trains an LMNN metric on X supervised by labels via climclusterpy.clustering.lmnn.train_lmnn(), then

  2. builds a SciPy linkage and cuts it to n_clusters.

The bridge from metric to linkage depends on the mode:

  • "global" — learns a linear transform L; clustering runs on the transformed features X @ L.T with ordinary Euclidean linkage (cheap; no dense distance matrix is materialized).

  • "local" / "enhanced" — learns a per-cell (diagonal) metric realized as a dense precomputed distance matrix D; clustering runs on D.

  • "lowrank" — learns a per-cell low-rank Mahalanobis metric (M_i = L_i L_iᵀ, L_i of shape (d, rank)), also realized as a dense D. Unlike the diagonal modes it captures cross-feature interaction; this is the configuration the published results deploy.

Parameters:

  • X (numpy.ndarray) – Standardized feature matrix, shape (n_cells, n_features).

  • labels (numpy.ndarray) – Supervision labels, shape (n_cells,) — e.g. Köppen-Geiger codes, ecoregion IDs, or output-cluster labels. For "local"/"enhanced" modes the labels are integer-encoded internally (the torch trainers require contiguous integer classes); "global" accepts arbitrary label values.

  • n_clusters (int) – Number of clusters to cut the dendrogram into.

  • mode (str, optional) – LMNN mode: "global" (default), "local", "enhanced" or "lowrank".

  • linkage_method (str, optional) – SciPy linkage method (default "complete", matching the production path).

  • rank (int or None, optional) – Rank of the learned metric, for the two modes that have one. mode="global": number of rows of the linear map L (None = full rank). mode="lowrank": rank r of each cell’s Mahalanobis factor (None = 16, the setting the published results use on 25 features). A rank above the number of features is lowered to it. The diagonal modes ("local", "enhanced") have no rank and raise if given one.

  • k (int or None, optional) – LMNN target-neighbour count (default 5). Not accepted by mode="lowrank", which derives it per anchor.

  • seed (int or None, optional) – Seed every RNG the torch-backed modes draw from. None (default) leaves them untouched, so local/enhanced/lowrank are not reproducible; pass a seed for any run whose numbers you will cite.

  • verbose (bool, optional) – Forwarded to train_lmnn().

  • return_distance_matrix (bool, optional) – Keep the dense per-cell distance matrix in the result (default False). Required to select medoid representatives downstream.

  • return_model (bool, optional) – Keep the trained per-cell metric network in the result (default False). Not available for mode="global", which learns no network.

  • **lmnn_kwargs – Extra keyword arguments forwarded verbatim to train_lmnn() (e.g. max_iter for global mode, or max_epochs/margin for local modes). A name the selected trainer does not accept raises TypeError.

Returns:

The cluster labels, linkage, and metric artifacts.

Return type:

LmnnClusteringResult

Raises:

  • ValueError – If mode is not one of "global", "local", "enhanced", "lowrank", or rank is given to a diagonal mode.

  • ImportError – If torch (the [lmnn] extra) is not installed.

train_lmnn(X, labels, mode='global', k=None, max_iter=1000, hidden_dims=None, margin=1.0, learning_rate=None, batch_size=128, max_epochs=100, dropout=0.1, weight_decay=0.0001, patience=10, rank=None, seed=None, verbose=False, **kwargs)[source]

Train an LMNN metric-learning model in one of four modes.

Parameters:

  • X (numpy.ndarray) – Feature matrix (n_samples, n_features); should be standardized.

  • labels (numpy.ndarray) – Class labels (e.g. ecoregion IDs), shape (n_samples,).

  • mode (str, optional) – "global" learns one linear map L for all cells (classic LMNN); "local" learns feature-conditioned diagonal local weights via a neural network; "enhanced" adds prototypes and oversampling to the diagonal metric; "lowrank" learns a per-cell low-rank Mahalanobis metric that captures cross-feature interaction (the published configuration, rank=16 on 25 features). Default "global".

  • k (int or None, optional) – Number of target neighbours (default 5). Not accepted by mode="lowrank", which derives k per anchor from k_min, k_max and beta.

  • max_iter (int, optional) – Global mode only: maximum number of training iterations (default 1000).

  • hidden_dims (list of int, optional) – Local/enhanced modes: hidden-layer sizes for the network (default [64, 32]).

  • margin (float, optional) – Global, local and enhanced modes: impostor separation margin (default 1.0).

  • learning_rate (float or None, optional) – Optimiser step size. None (default) uses the mode’s own default: 1e-2 for global mode (Adam on the entries of L), 1e-3 for the network modes.

  • batch_size (int, optional) – Network modes only: training batch size (default 128).

  • max_epochs (int, optional) – Network modes only: maximum training epochs (default 100).

  • dropout (float, optional) – Network modes only: dropout probability (default 0.1).

  • weight_decay (float, optional) – Local/enhanced/lowrank only: L2 regularization strength (default 1e-4).

  • patience (int, optional) – Network modes only: early-stopping patience (default 10).

  • rank (int or None, optional) – Rank of the learned metric. mode="global": number of rows of L (None = full rank, n_features). mode="lowrank": rank of each cell’s metric factor (None = 16, the published setting on 25 features). A rank above n_features is lowered to n_features. The diagonal modes ("local", "enhanced") have no rank, so passing it there raises.

  • seed (int or None, optional) – Seed for every RNG the trainer draws from. None (default) leaves the global RNGs untouched, so the network modes are not reproducible; pass a seed for any run whose numbers you intend to cite. Global mode has no random component and is reproducible either way.

  • verbose (bool, optional) – Log training progress (default False).

  • **kwargs – Further options of the trainer the mode runs: train_global_lmnn() (e.g. push_weight, n_candidates, refresh_every), train_local_lmnn(), train_enhanced_local_lmnn() or train_local_mahalanobis_lmnn(). A name that trainer does not accept raises TypeError.

Returns:

For mode="global": (L, M, diagnostics) – the linear map L of shape (rank, n_features), the Mahalanobis matrix M = L.T @ L of shape (n_features, n_features), and a diagnostics dict (loss history, convergence info, the rank used). For the other modes: (model, distance_fn, diagnostics) – the trained network, a callable computing the pairwise distance matrix (distance_fn(X) -> D), and a diagnostics dict.

Return type:

tuple

Raises:

  • ImportError – If PyTorch (the [lmnn] extra) is not installed.

  • ValueError – For an unknown mode, or rank/k given to a mode that cannot honour it.

  • TypeError – For a keyword argument the selected trainer does not accept.

Notes

Global mode assumes one universal feature weighting across all cells, while the per-cell modes let the metric vary with local environmental context (e.g. temperature matters more in the tropics).

Examples

Global LMNN:

L, M, diag = train_lmnn(X, labels, mode="global", rank=10, seed=0)
X_transformed = transform_features(X, L)

Local LMNN:

model, distance_fn, diag = train_lmnn(X, labels, mode="local", seed=0)
D = distance_fn(X)  # pairwise distances

class LDAMetricLearner(supervision='kg', cache_dir=None, force_recompute=False)[source]

Bases: object

LDA-based metric learner for ecological clustering.

Fits scikit-learn’s LinearDiscriminantAnalysis with solver='eigen' and shrinkage='auto' (Ledoit-Wolf shrinkage) on a feature matrix X supervised by either Köppen-Geiger zone labels or ecoregion labels.

The fitted discriminant axes define a lower-dimensional space (at most n_classes − 1 dimensions) in which same-class cells cluster tightly and different-class cells are well separated, analogous to what LMNN achieves via a Mahalanobis matrix.

Parameters:

  • supervision ({'kg', 'ecoregion'}) – Which label set was used for supervision. Stored as metadata and reflected in the default cache filename.

  • cache_dir (str or Path, optional) – Directory in which to persist the fitted model as lda_<supervision>_<fingerprint>.pkl, the fingerprint being that of the X and y it was fitted on. When that file already exists and force_recompute=False, the stored model is loaded instead of refitting; a model fitted on other data is never loaded.

  • force_recompute (bool) – When True, ignore any existing cache and always refit.

lda_

The per-cell trainers and their distance matrices

The pieces behind the per-cell modes, for anyone tuning or extending them. They need torch and are loaded on first use:

  • train_local_lmnn, train_enhanced_local_lmnn, train_local_mahalanobis_lmnn — the three per-cell trainers behind lmnn_mode="local", "enhanced" and "lowrank";

  • compute_distance_matrix_local, compute_local_mahalanobis_distance_matrix — the n × n distance matrix under a trained diagonal or low-rank network.

Their docstrings are the reference: help(climclusterpy.clustering.lmnn.train_local_lmnn).
