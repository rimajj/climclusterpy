Source code for climclusterpy.grid.native

"""Placing each reduced cell where its climate came from, on the source grid's own lattice.

A reduced grid holds one cell per cluster, and each of those cells carries some real cell's
climate — the representative member's, written straight out of the timeseries file. *Where*
the cell is placed is a separate decision, and
:func:`~climclusterpy.grid.build.create_regular_grid_from_dataset` makes it differently: it
places the cell at the cluster's ``center_lat``, the latitude of whichever member sits
nearest the cluster's median **absolute** latitude. Those are two different cells. Measured
across 26 real cluster sets, 17–100 % of clusters were separated from the latitude of their
own climate, by up to 107°, with 3 to 224 clusters per set landing in the opposite
hemisphere — up to 9.545 hours of day length, which is the one channel by which latitude
reaches the vegetation in a run whose radiation comes from a forcing file.

This module places each cell at the coordinates of the cell whose climate it carries instead.
Four rules:

1. **Coordinates come from the representative cell.** ``center_lat``/``center_lon`` stay
   cluster descriptors; they stop being the grid coordinate.
2. **The latitude lattice is the source grid's own**, anchored on a real source latitude —
   no spacing search. A representative cell's latitude already *is* a source latitude, so
   the displacement is exactly zero rather than small, and the build fails if it is not.
3. **Columns are one source cell apart**, as many as the busiest latitude row needs, so the
   axis step the CLM converter writes into the header — what the vegetation model reads back
   as ``config->resolution``, and what scales every area-weighted total — is the source cell
   size.
4. **Five checks fail the build** rather than warn: the latitude axis is strictly uniform at
   the source spacing; no cell was displaced; both declared cell sizes equal the source cell
   size; the longitude axis is uniform and inside the ±180° the CLM tools accept; and, on the
   file actually written, every cluster occupies its own slots and the compact map agrees
   with them.

The last three are checked twice — once on the axes this module computes, once by
:func:`build_reduced_grid` on the NetCDF that came out — because the guarantee that matters
is about the artifact, not about intent.

Why hard failures: ``cdf2clm`` reads each axis's step from the first and last coordinate only
and never inspects the interior, and the return value of its own check is commented out. A
non-uniform latitude axis therefore gives every cell the wrong row's climate, silently. That
is a correctness guard, never a warning.

The written **longitudes are fiction** under every compact construction, this one included:
the columns are a packed block, not each cell's own meridian. That is admissible only because
longitude is physically inert in this configuration, so the check that keeps it admissible —
a uniform longitude axis inside ±180°, with every cluster's true coordinates written to the
placement CSV — belongs here beside the other four.
"""

#: The floor of every coordinate tolerance here, in degrees. ``_axis_tolerance`` adds what
#: COORD_PRECISION rounding and float32 storage can introduce:
#: anything tighter rejects exact inputs -- a 9 km grid's float32 latitudes sit up to ~7e-6°
#: off their lattice -- while the smallest real displacement is a whole source cell.
ON_LATTICE_ATOL: float = 1e-6

class NativePlacement(NamedTuple):
    """Where every reduced cell sits, and the lattice it sits on.

    A six-field tuple in the order
    :func:`~climclusterpy.grid.build.create_cluster_nc_files` expects for its
    ``precomputed_grid`` argument, so it can be handed straight over; the names are here so a
    caller can read the placement instead of unpacking it positionally.

    Attributes
    ----------
    grid_lats : numpy.ndarray
        One latitude per written cell, ``n_clusters * n_repeat`` long.
    grid_lons : numpy.ndarray
        The longitude axis, one entry per column.
    adjusted_lats : numpy.ndarray
        The latitude each cluster is placed at, in dataset order, ``n_clusters`` long. Under
        this construction it equals the representative cell's own latitude exactly.
    global_lons : numpy.ndarray
        The longitude axis again (the shape ``create_cluster_nc_files`` reads).
    lat_spacing : float
        The latitude step — the source grid's own cell size.
    lat_offset : float
        The real source latitude the lattice is anchored on.
    """

    grid_lats: np.ndarray
    grid_lons: np.ndarray
    adjusted_lats: np.ndarray
    global_lons: np.ndarray
    lat_spacing: float
    lat_offset: float




def _per_cluster_coordinates(ds: xr.Dataset) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    """The representative cell's own coordinates, one pair per cluster, in dataset order."""
    missing = [n for n in ("cluster_label", "latitude", "longitude") if n not in ds]
    if missing:
        raise KeyError(
            f"Native placement needs {missing} in the timeseries dataset: the cell is placed "
            f"at the coordinates of the cell whose climate it carries, and 'latitude'/"
            f"'longitude' are where the representative extractor records them."
        )

    labels = np.asarray(ds["cluster_label"].values).reshape(-1).astype(int)
    lat = np.asarray(ds["latitude"].values, dtype=float).reshape(-1)
    lon = np.asarray(ds["longitude"].values, dtype=float).reshape(-1)

    if not (len(lat) == len(lon) == len(labels)):
        raise ValueError(
            f"Native placement needs exactly one coordinate pair per cluster; got "
            f"{len(labels)} labels, {len(lat)} latitudes and {len(lon)} longitudes. A "
            f"distributed-mode timeseries file carries several cells per cluster and reaches "
            f"the grid through a different branch — it is not covered by this construction."
        )
    if len(np.unique(labels)) != len(labels):
        raise ValueError(
            f"Native placement needs one row per cluster, but 'cluster_label' repeats "
            f"({len(labels)} rows, {len(np.unique(labels))} distinct labels)."
        )
    return labels, lat, lon


def _axis_tolerance(axis: np.ndarray) -> float:
    """How far apart two steps of one axis may be before the axis is genuinely uneven.

    Coordinates are stored as float32 (``COORD_DTYPE``), whose spacing at latitude 90 is
    about 7.6e-06°, so a perfectly regular axis whose values are not exactly representable
    comes back with steps that differ in the sixth decimal. Coordinates are also rounded to
    ``COORD_PRECISION`` decimals, each value on its own, so a step like 0.0703125° comes back
    as 0.07031 or 0.07032 -- an error that does not accumulate along the axis. The hazard this
    guards against — ``cdf2clm`` indexing an axis whose real steps differ — is orders of
    magnitude coarser than either, so the tolerance follows the storage precision rather than
    fighting it. (Before 0.3.0 the rounding term was missing, which refused the 9 km grid.)
    """
    scale = float(np.max(np.abs(np.asarray(axis, dtype=float)))) if len(axis) else 1.0
    storage = 10.0 ** (-COORD_PRECISION) + 8.0 * float(np.finfo(np.float32).eps) * scale
    return max(ON_LATTICE_ATOL, storage)


def _uniform_step(axis: np.ndarray, expected: float, what: str) -> None:
    """Fail unless ``axis`` is strictly increasing with a constant step of ``expected``."""
    if len(axis) < 2:
        raise ValueError(
            f"The {what} has {len(axis)} entries. The CLM tools need at least two, because "
            f"they take the axis step from its first and last coordinate."
        )
    steps = np.diff(np.asarray(axis, dtype=float))
    if not np.all(np.abs(steps - expected) <= _axis_tolerance(axis)):
        raise ValueError(
            f"The {what} is not uniform at {expected}°: steps run from {steps.min():.8f}° to "
            f"{steps.max():.8f}°. cdf2clm reads the step from the first and last coordinate "
            f"only and never inspects the interior, so a non-uniform axis gives every cell "
            f"the wrong row's climate with no warning."
        )

def create_native_grid_from_dataset(
    ds: xr.Dataset,
    n_repeat: int = 1,
    output_dir: str | None = None,
    *,
    source_spacing: float,
    lat_anchor: float | None = None,
    lon_origin: float | None = None,
) -> NativePlacement:
    """Place every cluster at its representative cell's coordinates, on the source lattice.

    The drop-in alternative to
    :func:`~climclusterpy.grid.build.create_regular_grid_from_dataset`: same six-field
    return, no spacing search, and no free parameter to tune — the lattice is the source
    grid's, and the placement is the cell's own.

    Parameters
    ----------
    ds : xarray.Dataset
        The cluster timeseries dataset, one entry per cluster along ``cluster``, carrying
        ``cluster_label`` and the representative cell's ``latitude``/``longitude``. This is
        what :func:`~climclusterpy.timeseries.extract_representative_cells`
        writes.
    n_repeat : int, optional
        Cells written per cluster (default 1). Each cluster gets ``n_repeat`` adjacent
        columns, so a row's width is the busiest cluster count times this.
    output_dir : str, optional
        Where to write the two placement records. When given,
        ``cell_placement_{K}.csv`` (every cluster's true coordinates, the slot it occupies,
        and its displacement — all zero by construction) and ``latitude_adjustments_{K}.csv``
        (the same thing in the column names the reconstruction path already reads) land here.
        Writing them is what keeps the fictional longitude axis admissible: the true
        coordinates are recorded even though the axis cannot carry them.
    source_spacing : float
        The source grid's cell size in degrees — 0.5 for a half-degree grid. Required, and
        deliberately not inferred: guessing it is exactly the silent decision this
        construction exists to remove.
    lat_anchor : float, optional
        The real source latitude the lattice is anchored on. Defaults to the southernmost
        representative latitude, which is a source latitude by definition.
    lon_origin : float, optional
        Where the packed column block starts. Defaults to the westernmost representative
        longitude, shifted west only as far as needed to keep the block inside ±180°.

    Returns
    -------
    NativePlacement
        Hand it to :func:`~climclusterpy.grid.build.create_cluster_nc_files` as
        ``precomputed_grid=``, with ``lon_spacing=source_spacing``, or let
        :func:`build_reduced_grid` do both.

    Raises
    ------
    ValueError
        If any representative latitude does not already lie on the source lattice, if either
        declared cell size would differ from ``source_spacing``, if the packed block cannot
        fit inside ±180°, or if the dataset does not carry one coordinate pair per cluster.
        Every one of these is a silent-wrong-answer condition downstream, so none of them
        warns.

    Examples
    --------
    >>> import numpy as np, xarray as xr
    >>> ds = xr.Dataset(
    ...     {
    ...         "cluster_label": ("cluster", np.array([1, 2, 3])),
    ...         "latitude": ("cluster", np.array([-0.25, 10.25, 10.25])),
    ...         "longitude": ("cluster", np.array([12.25, -3.75, 40.25])),
    ...     }
    ... )
    >>> placement = create_native_grid_from_dataset(ds, source_spacing=0.5)
    >>> placement.adjusted_lats.tolist()
    [-0.25, 10.25, 10.25]
    >>> placement.lat_spacing, placement.lat_offset
    (0.5, -0.25)
    """
    labels, rep_lat, rep_lon = _per_cluster_coordinates(ds)
    n_clusters = len(labels)

    if int(n_repeat) < 1:
        raise ValueError(f"n_repeat must be at least 1, got {n_repeat}")
    n_repeat = int(n_repeat)

    d = float(source_spacing)
    if not d > 0:
        raise ValueError(f"source_spacing must be positive, got {source_spacing}")

    # --- rule 2: the source grid's own lattice, anchored on a real source latitude --------
    anchor = float(np.min(rep_lat)) if lat_anchor is None else float(lat_anchor)
    anchor = float(np.round(anchor, COORD_PRECISION))

    k_lat = np.rint((rep_lat - anchor) / d)
    placed_lat = np.round(anchor + k_lat * d, COORD_PRECISION)

    # --- rule 1 + its check: the cell is placed where its climate came from, exactly ------
    displacement = np.abs(placed_lat - rep_lat)
    # Both the latitude and its lattice point carry rounding and float32 error. Before 0.3.0
    # this was ON_LATTICE_ATOL alone (1e-6°), which refused every grid whose latitudes are not
    # exactly representable -- the 0.0703125° German grid among them.
    tolerance = _axis_tolerance(rep_lat)
    if displacement.max() > tolerance:
        worst = int(np.argmax(displacement))
        raise ValueError(
            f"{int((displacement > tolerance).sum())} of {n_clusters} representative "
            f"latitudes do not lie on a {d}° lattice anchored at {anchor}°; the worst is "
            f"cluster {labels[worst]} at {rep_lat[worst]}°, which would have to move "
            f"{displacement[worst]:.6f}° to {placed_lat[worst]}°. This construction moves no "
            f"cell — displacement is exactly zero or the build fails. Pass the source grid's "
            f"real cell size and an anchor taken from it, or, if these latitudes genuinely "
            f"do not lie on a regular lattice, ask for the spacing search explicitly via "
            f"create_regular_grid_from_dataset. A displaced cell would carry one latitude's "
            f"climate at another latitude's day length and radiation."
        )

    # --- rule 3: columns one source cell apart, as many as the busiest row needs ----------
    _, per_lat_counts = np.unique(placed_lat, return_counts=True)
    n_lon = int(per_lat_counts.max()) * n_repeat
    # create_cluster_nc_files forces at least two columns (a 1-wide grid is not a grid to the
    # CLM tools); keep the axis in step with that so the declared cell size holds either way.
    n_lon_axis = max(n_lon, 2)

    span = (n_lon_axis - 1) * d
    if lon_origin is None:
        lon0 = float(np.min(np.where(rep_lon > 180.0, rep_lon - 360.0, rep_lon)))
        lon0 = min(lon0, 180.0 - span)
    else:
        lon0 = float(lon_origin)
    lon0 = float(np.round(lon0, COORD_PRECISION))

    if lon0 < -180.0 or lon0 + span > 180.0:
        raise ValueError(
            f"The busiest latitude row needs {n_lon_axis} columns, which one source cell "
            f"({d}°) apart span {span}° from {lon0}° — outside the ±180° the CLM tools "
            f"accept. Raise n_repeat's denominator or split the build; a wrapped longitude "
            f"axis is not uniform, and cdf2clm would not notice."
        )

    axis_lon = standardize_coordinates(
        np.round(lon0 + np.arange(n_lon_axis) * d, COORD_PRECISION), "reduced-grid longitudes"
    )

    # --- rule 4: the checks, on the axes this function returns ----------------------------
    k_full = np.arange(int(k_lat.min()), int(k_lat.max()) + 1)
    axis_lat = standardize_coordinates(
        np.round(anchor + k_full * d, COORD_PRECISION), "reduced-grid latitudes"
    )
    # A single populated row is expanded to two by the writer, at +lat_spacing, which stays
    # uniform; the uniformity check needs the axis it will actually write.
    _uniform_step(
        axis_lat if len(axis_lat) > 1 else np.array([axis_lat[0], axis_lat[0] + d]),
        d,
        "latitude axis",
    )
    _uniform_step(axis_lon, d, "longitude axis")

    for name, axis in (("latitude", axis_lat), ("longitude", axis_lon)):
        if len(axis) > 1 and abs(float(axis[1] - axis[0]) - d) > _axis_tolerance(axis):
            raise ValueError(
                f"The declared {name} cell size would be {float(axis[1] - axis[0])}° instead "
                f"of the source grid's {d}°. That step is what cdf2clm writes into the "
                f"header and the model reads back as config->resolution, so it scales every "
                f"area-weighted total the run reports."
            )

    if output_dir is not None:
        _write_placement_records(
            output_dir,
            labels=labels,
            rep_lat=rep_lat,
            rep_lon=rep_lon,
            placed_lat=placed_lat,
            displacement=displacement,
            # The row index is arithmetic, never a coordinate lookup: k counts lattice steps
            # from the anchor, so it survives the float32 the axis is stored as.
            lat_index=(k_lat - k_lat.min()).astype(int),
            n_repeat=n_repeat,
        )

    return NativePlacement(
        grid_lats=np.repeat(placed_lat, n_repeat),
        grid_lons=axis_lon,
        adjusted_lats=placed_lat,
        global_lons=axis_lon,
        lat_spacing=d,
        lat_offset=anchor,
    )




def _write_placement_records(
    output_dir: str,
    *,
    labels: np.ndarray,
    rep_lat: np.ndarray,
    rep_lon: np.ndarray,
    placed_lat: np.ndarray,
    displacement: np.ndarray,
    lat_index: np.ndarray,
    n_repeat: int,
) -> tuple[str, str]:
    """Write the two records that keep the packed longitude axis honest.

    ``cell_placement_{K}.csv`` is the disclosure: each cluster's true coordinates beside the
    slot it occupies, so nothing downstream has to invert the fictional longitude axis.
    ``latitude_adjustments_{K}.csv`` carries the same placement under the column names the
    reconstruction path already reads, and writing it here — rather than letting
    ``create_cluster_nc_files`` synthesize one from ``center_lat`` — is what stops that file
    from recording the 107° centre-vs-representative separation as if it were a displacement.
    """
    os.makedirs(output_dir, exist_ok=True)
    n_clusters = len(labels)

    # Position within the row, in dataset order — the same rule create_netcdf_from_dataset
    # uses when it hands out columns, so the record describes the file that gets written.
    position_in_row = np.empty(n_clusters, dtype=int)
    seen: dict[float, int] = {}
    for i, lat in enumerate(placed_lat):
        key = float(lat)
        position_in_row[i] = seen.get(key, 0)
        seen[key] = position_in_row[i] + 1

    placement_path = os.path.join(output_dir, f"cell_placement_{n_clusters}.csv")
    pd.DataFrame(
        {
            "cluster_label": labels,
            "source_lat": rep_lat,
            "source_lon": rep_lon,
            "grid_lat": placed_lat,
            "lat_index": lat_index,
            "column_start": position_in_row * n_repeat,
            "n_repeat": n_repeat,
            "lat_displacement_deg": displacement,
        }
    ).to_csv(placement_path, index=False)

    adjustments_path = os.path.join(output_dir, f"latitude_adjustments_{n_clusters}.csv")
    pd.DataFrame(
        {
            "cluster_label": labels,
            "original_lon": rep_lon,
            "original_lat": rep_lat,
            "adjusted_lat": placed_lat,
            "deviation": displacement,
        }
    ).to_csv(adjustments_path, index=False)
    return placement_path, adjustments_path

def build_reduced_grid(
    timeseries_dataset: xr.Dataset,
    output_dir: str,
    *,
    source_spacing: float,
    labels_csv: str | None = None,
    n_repeat: int = 1,
    npatch: int = 1,
    timeseries_type: str = "representative",
    aggregation_type: str = "clustering",
    cluster_method: str | None = None,
    artifacts_dir: str | None = None,
    id_mapping_file: str | None = None,
    lat_anchor: float | None = None,
    lon_origin: float | None = None,
    overwrite: bool = True,
) -> dict[str, str]:
    """Write a model-ready reduced grid with every cell where its climate came from.

    One call for the build half of the round trip: it places the cells
    (:func:`create_native_grid_from_dataset`), writes one NetCDF per forcing variable plus
    the mapping CSVs the projection back reads
    (:func:`~climclusterpy.grid.build.create_cluster_nc_files`), and then re-opens what it
    wrote to check the guarantees on the artifact rather than on the intent.

    The other half is :func:`~climclusterpy.reconstruct_original_grid`, which needs nothing
    from this function but the two CSVs: it places values by cluster label and row index,
    never by coordinate, so where a cell sits changes the science but not the projection.

    Parameters
    ----------
    timeseries_dataset : xarray.Dataset
        One entry per cluster, carrying ``cluster_label``, the representative cell's
        ``latitude``/``longitude``, ``time``, and the forcing variables to write.
    output_dir : str
        Where the NetCDFs go.
    source_spacing : float
        The source grid's cell size in degrees (0.5 for a half-degree grid).
    labels_csv : str, optional
        The ``cell_id,cluster_label`` table for the whole original grid. Needed to write
        ``cluster_id_mapping_{K}.csv``, without which the projection back has no way to know
        which original cells a cluster stands for.
    n_repeat, npatch : int, optional
        Cells written per cluster, and patches per cluster, as
        :func:`~climclusterpy.grid.build.create_cluster_nc_files` defines them.
    timeseries_type, aggregation_type, cluster_method : str, optional
        Carried into the output filenames unchanged.
    artifacts_dir : str, optional
        Where the CSVs go; defaults to ``output_dir``.
    id_mapping_file : str, optional
        An existing ``cluster_id_mapping`` CSV to use instead of writing one.
    lat_anchor, lon_origin : float, optional
        Passed to :func:`create_native_grid_from_dataset`.
    overwrite : bool, optional
        When False, a variable whose NetCDF already exists and is non-empty is skipped.

    Returns
    -------
    dict
        Variable name to written path, plus ``"__id_mapping__"`` and ``"__placement__"``.

    Raises
    ------
    ValueError
        If the placement cannot be made faithfully (see
        :func:`create_native_grid_from_dataset`), or if the grid that was written does not
        carry the placement it was told to — a uniform axis at the source spacing, one slot
        block per cluster, and a compact map that points at those blocks.
    """
    _artifacts_dir = artifacts_dir if artifacts_dir is not None else output_dir
    placement = create_native_grid_from_dataset(
        timeseries_dataset,
        n_repeat=n_repeat,
        output_dir=_artifacts_dir,
        source_spacing=source_spacing,
        lat_anchor=lat_anchor,
        lon_origin=lon_origin,
    )

    files = create_cluster_nc_files(
        timeseries_dataset,
        output_dir,
        n_repeat=n_repeat,
        npatch=npatch,
        aggregation_type=aggregation_type,
        timeseries_type=timeseries_type,
        labels_csv=labels_csv,
        precomputed_grid=placement,
        id_mapping_file=id_mapping_file,
        cluster_method=cluster_method,
        overwrite=overwrite,
        artifacts_dir=_artifacts_dir,
        lon_spacing=source_spacing,
        # THIS build's compact map, beside THIS build's placement record. Without it a call
        # that reuses an ID mapping (`id_mapping_file=`) inherits whatever compact map sits
        # next to that mapping, which describes another grid — on four test grids 63 of 67
        # rows named a row outside the grid and 3 named another cluster's row, which is
        # applied silently. The map is the only thing
        # `reconstruct_original_grid` reads, so it must be this grid's own.
        compact_map_dir=_artifacts_dir,
    )

    written = [p for name, p in files.items() if not name.startswith("__")]
    if not written:
        raise ValueError(
            f"No reduced-grid NetCDF was written to {output_dir!r}: the timeseries dataset "
            f"carries no variable to write (only metadata)."
        )
    n_clusters = len(np.asarray(timeseries_dataset["cluster_label"].values).reshape(-1))
    verify_written_grid(
        written[0],
        source_spacing=source_spacing,
        n_clusters=n_clusters,
        n_repeat=n_repeat,
        compact_map_csv=os.path.join(_artifacts_dir, f"cluster_compact_map_{n_clusters}.csv"),
    )

    files["__placement__"] = os.path.join(_artifacts_dir, f"cell_placement_{n_clusters}.csv")
    return files

def verify_written_grid(
    path: str,
    *,
    source_spacing: float,
    n_clusters: int,
    n_repeat: int = 1,
    compact_map_csv: str | None = None,
) -> None:
    """Fail unless the NetCDF on disk carries the placement it was built with.

    Checks the three things a silently wrong grid gets wrong: the axes are uniform at the
    source spacing (so ``cdf2clm`` indexes them correctly and declares the right cell size),
    every cluster occupies its own ``n_repeat`` slots and no other cluster's, and — when the
    compact map is given — that map points at exactly those slots, which is the only thing
    the projection back reads.

    Give ``compact_map_csv`` a path and it must exist: a missing map is an error, not a
    skipped check.
    """
    with xr.open_dataset(path) as ds:
        lat = np.asarray(ds["latitude"].values, dtype=float)
        lon = np.asarray(ds["longitude"].values, dtype=float)
        labels_grid = (
            np.asarray(ds["cluster_label"].values) if "cluster_label" in ds.variables else None
        )

    _uniform_step(lat, float(source_spacing), f"latitude axis of {os.path.basename(path)}")
    _uniform_step(lon, float(source_spacing), f"longitude axis of {os.path.basename(path)}")

    if labels_grid is None:
        raise ValueError(
            f"{path} carries no cluster_label grid, so which cluster owns which slot cannot "
            f"be checked."
        )

    occupied = labels_grid >= 0
    expected_slots = n_clusters * n_repeat
    if int(occupied.sum()) != expected_slots:
        raise ValueError(
            f"{os.path.basename(path)} has {int(occupied.sum())} occupied slots, expected "
            f"{expected_slots} ({n_clusters} clusters × {n_repeat}). A cluster that lost its "
            f"slot was overwritten by another one, and the run would silently simulate the "
            f"wrong cell."
        )
    present, counts = np.unique(labels_grid[occupied], return_counts=True)
    if len(present) != n_clusters or not np.all(counts == n_repeat):
        raise ValueError(
            f"{os.path.basename(path)} holds {len(present)} distinct cluster labels with "
            f"slot counts {counts.min()}–{counts.max()}, expected {n_clusters} labels with "
            f"{n_repeat} each. A cluster whose slots were taken by another would be "
            f"simulated with the wrong climate, or not at all."
        )

    if compact_map_csv is None:
        return
    if not os.path.exists(compact_map_csv):
        # Absent is NOT "nothing to check". This check used to return quietly here, so a build
        # that failed to write the one table the projection back reads passed verification and
        # the run only broke a step later, at reconstruction — or worse, projected against a
        # map some other build had left lying around. A caller that gives
        # a path is asking for the check; no file means the check cannot be done.
        raise ValueError(
            f"{compact_map_csv} does not exist, so the map the projection back reads cannot be "
            f"checked against {os.path.basename(path)}. That map is the ONLY thing "
            f"`reconstruct_original_grid` uses to decide which original cells a simulated cell "
            f"stands for, so a grid built without one cannot be projected back at all."
        )
    cmap = pd.read_csv(compact_map_csv)
    for _, row in cmap.iterrows():
        label = int(row["cluster_label"])
        i = int(row["lat_index"])
        j0, j1 = int(row["cluster_index_start"]), int(row["cluster_index_end"])
        block = labels_grid[i, j0 : j1 + 1]
        if block.size == 0 or not np.all(block == label):
            raise ValueError(
                f"The compact map points cluster {label} at row {i}, columns {j0}–{j1} of "
                f"{os.path.basename(path)}, which holds {np.unique(block).tolist()}. That "
                f"map is the only thing the projection back reads, so a disagreement puts "
                f"one cluster's simulation onto another cluster's cells."
            )
