Reconstruction correctness

Reconstruction maps every original land cell back to its cluster’s value using strict ID mapping (no coordinate matching). When the number of clusters approaches the number of cells, several clusters can share a single latitude row on the artificial grid, so the reconstruction reads the exact longitude span of each cluster from the compact row map (cluster_compact_map_{K}.csv) rather than averaging whole rows. See Reconstruct the original grid for the mapping files each reconstruction path requires.
