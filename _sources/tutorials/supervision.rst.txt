Tutorial 3: supervision signals
===============================

:func:`~climclusterpy.compute_supervision` builds the per-cell class labels that LMNN learns
from. This tutorial uses the two sources that run on small synthetic data: Köppen–Geiger
classes (from climate) and model output (from traits). The last section outlines ecoregions,
which need a shapefile and the ``[ecoregions]`` extra.

Köppen–Geiger from monthly climatology
--------------------------------------

The package computes Köppen–Geiger classes from a monthly-climatology feature table with 12
monthly temperature (°C) and precipitation (mm/month) columns per cell, plus ``cell_id``,
``latitude`` and ``longitude``. The helper builds that table from the synthetic series:

.. code-block:: python

   from climclusterpy import compute_supervision
   from _synthetic import monthly_climatology_df

   kg_features = monthly_climatology_df(datasets, registry)
   kg = compute_supervision("koppen_geiger", features_df=kg_features, output_dir=tmp)
   kg.n_classes            # number of KG classes present
   kg.encoded_y            # 0..n_classes-1 labels, aligned to the cells

Model output (traits)
---------------------

``kind="output"`` clusters cells by the similarity of simulated traits, given as a table with
one row per cell. Pass the trait columns as ``continuous_cols`` and the coordinates as
parallel arrays:

.. code-block:: python

   out = compute_supervision(
       "output",
       features_df=traits,
       cell_ids=traits["cell_id"].to_numpy(),
       latitudes=traits["latitude"].to_numpy(),
       longitudes=traits["longitude"].to_numpy(),
       continuous_cols=["vegc", "height", "sla"],
       n_clusters=5,
       output_dir=tmp,
   )

Each call returns a :class:`~climclusterpy.SupervisionResult`. Its ``.labels`` is the
canonical ``cell_id/latitude/longitude/cluster_label`` table, ``.labels_csv`` is the CSV on
disk, and ``.y`` and ``.encoded_y`` go to :func:`~climclusterpy.cluster_matrix`.

Ecoregion supervision
---------------------

The third source assigns cells to WWF Ecoregions2017 polygons by a spatial join. It needs
the ``[ecoregions]`` extra and a shapefile, so the tutorial does not run it on synthetic data:

.. code-block:: python

   sup = compute_supervision(
       "ecoregions",
       registry=registry,
       ecoregions_shapefile="Ecoregions2017/Ecoregions2017.shp",
   )

See :doc:`../howto/supervision` for details and :doc:`lmnn_clustering` for how to use the signal.
