Tutorial 1 — Euclidean clustering
=================================

This tutorial builds a synthetic climate and soil grid, derives a per-cell feature matrix
and groups the cells into *K* clusters under the Euclidean distance. This mode needs no
supervision and only the base install.

Load data and build a feature matrix
------------------------------------

The shared helper writes synthetic NetCDF files and loads them through the data loader of
the package, returning a :class:`~climclusterpy.data.DataRegistry` and a feature matrix
``X`` of shape ``(n_valid_cells, n_features)``:

.. code-block:: python

   from _synthetic import feature_matrix, load_synthetic

   _paths, datasets, registry = load_synthetic(tmp, n_cells=64)
   X, meta = feature_matrix(datasets, registry)   # X: (64, 8); meta: cell_id/lat/lon

Cluster
-------

:func:`~climclusterpy.cluster_matrix` with ``locally_weighted=False`` runs agglomerative
clustering. ``standardize=True`` z-scores each feature first:

.. code-block:: python

   from climclusterpy import cluster_matrix

   result = cluster_matrix(X, n_clusters=6, locally_weighted=False, standardize=True)
   result.labels           # 1-indexed label per cell, shape (64,)
   result.to_frame()       # cell_id + cluster_label

The result carries the SciPy ``linkage`` matrix, from which a different *K* can be cut
without clustering again, and, for a DataFrame input, the metadata columns.
