Tutorial 4 — Reconstruct the original grid
==========================================

This tutorial runs the reconstruction on synthetic data: it clusters the cells, writes a
synthetic "model output" NetCDF on the reduced grid together with the two mapping CSVs,
reconstructs the output onto every original cell and verifies that each cell received the
value of its group.

Reconstruction
--------------

After clustering (:doc:`euclidean_clustering`), the example writes a reduced-grid output
NetCDF laid out as one latitude row with one longitude column per group, plus:

* ``cluster_id_mapping_{K}.csv``: every original cell and its group;
* ``cluster_compact_map_{K}.csv``: each group's ``lat_index`` and column span on the
  reduced grid.

:func:`~climclusterpy.reconstruct_original_grid` consumes both, with the grid description,
and writes the reconstructed grid. Without a :func:`~climclusterpy.create_clusters` result,
the three are passed explicitly:

.. code-block:: python

   from climclusterpy import reconstruct_original_grid

   recon_path = reconstruct_original_grid(
       clustered_nc,
       registry=registry,
       id_mapping_csv=id_csv,
       compact_map_csv=compact_csv,    # where each cluster sits on the reduced grid
       output_dir=out_dir,
   ).path

Check
-----

Every valid cell must carry the synthetic value of its group, and invalid (ocean) cells
must stay ``NaN``. The example checks each cell and then calls
:func:`~climclusterpy.grid.validate_reconstruction_grid`:

.. code-block:: python

   from climclusterpy.grid import validate_reconstruction_grid

   assert validate_reconstruction_grid(recon_path, registry, var_name="vegc")
