Tutorial 0: the whole workflow in two calls
===========================================


This tutorial reduces a climate grid to *K* groups, takes the output of a (synthetic) model
run on the reduced grid and rebuilds the original grid from it. It needs two function calls
and the base install only.

Running a land-surface model on a full global grid is expensive. When you group cells by
similarity, you need to run the model on only one cell per group, or a few (see
:doc:`../howto/cell_selection`), and every original cell then receives the output simulated
for its group. ``climclusterpy`` provides the two ends of this workflow:

.. code-block:: python

   from climclusterpy import create_clusters, reconstruct_original_grid

   clusters = create_clusters(
       climate={"temperature": "/data/tas.nc", "precipitation": "/data/pr.nc"},
       static={"soil": ("/data/soil.nc", "categorical")},
       n_clusters=2000,
   )
   # ... run your model on clusters.netcdf_files ...
   full = reconstruct_original_grid("vegc_output.nc", clusters=clusters)

Build the reduced grid
----------------------

:func:`~climclusterpy.create_clusters` takes the climate fields by name (``climate=``,
each a NetCDF with a time axis) and any static fields (``static=``, each declared
categorical or continuous). :doc:`../howto/inputs` lists the other ways to describe the
input. The function then:

1. loads the input and builds the registry of valid cells;
2. summarizes each cell into ecological features (annual means, seasonality, Köppen
   diagnostics, the static fields), then standardizes, de-correlates and PCA-filters them;
3. clusters the cells;
4. selects the cells to simulate in each group;
5. writes the reduced-grid NetCDFs and the two mapping CSVs that record which original
   cells each reduced cell stands for.

.. code-block:: python

   clusters = create_clusters(
       climate={
           "temperature": files.temperature,
           "precipitation": files.precipitation,
           "short_wave_radiation": files.short_wave_radiation,
       },
       static={"soil_depth": (files.soil_depth, "continuous")},
       n_clusters=6,
       output_dir="./clusters",
   )
   clusters.cluster_files      # the NetCDFs your model reads
   clusters.labels             # cell_id, latitude, longitude, cluster_label
   clusters.id_mapping_csv     # reduced cell -> original cells
   clusters.compact_map_csv    # row map for correct lon slicing at large K

Learned distance
~~~~~~~~~~~~~~~~

The Euclidean distance weights all features equally. With ``locally_weighted=True``, the
package first learns a distance, so that the directions in feature space that separate
ecologically different cells count for more. This needs the ``[lmnn]`` extra:

.. code-block:: python

   clusters = create_clusters(
       climate={"temperature": "/data/tas.nc", "precipitation": "/data/pr.nc"},
       n_clusters=2000,
       locally_weighted=True,
       supervision_data="/data/model_output/trait_grids",   # or a per-cell CSV
       supervision=["sla", "wooddens", "height", "biomass"],
   )

``supervision_data`` can be a directory of per-trait NetCDFs or a prepared per-cell CSV, and
the package detects the form automatically. Without ``supervision_data``, the package
computes Köppen–Geiger classes from the climate input, so the learned distance needs no
extra data.

With a learned metric, the cell simulated for each group defaults to its medoid (the member
with the smallest total distance to the others, measured in that metric) instead of the
member nearest the cluster mean.

Rebuild the original grid
-------------------------

:func:`~climclusterpy.reconstruct_original_grid` takes the model output and the ``clusters``
object, which holds the registry and both mapping CSVs:

.. code-block:: python

   full = reconstruct_original_grid("vegc_run.nc", clusters=clusters)
   full.path      # the reconstructed NetCDF
   full.files     # {source: reconstructed} for every input

It accepts a single file, a list or a directory of model output. It matches cells by group
label, not by coordinate, and cells outside the valid mask stay ``NaN``.
:ref:`reconstruction-check` describes how the package checks the result.

Run it
------

.. code-block:: console

   $ python examples/example_0_one_call_roundtrip.py
   create_clusters -> 6 clusters (euclidean mode, centroid cell selection)
     6 cluster NetCDFs in /tmp/.../clusters
     labels for 64 original cells -> .../cluster_labels_with_coords_nr_of_clusters_6.csv
     id mapping:  cluster_id_mapping_6.csv
     compact map: cluster_compact_map_6.csv
   reconstruct_original_grid -> /tmp/.../reconstructed/vegc_run_reconstructed.nc
   OK: all 64 original cells recovered their cluster's value.
