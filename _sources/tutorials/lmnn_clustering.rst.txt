Tutorial 2: LMNN metric-learning clustering
===========================================

This tutorial clusters the same synthetic grid with ``locally_weighted=True``. The package
learns a distance from a supervision signal before clustering, so that cells of the same
supervision class are grouped together. It needs PyTorch (``pip install climclusterpy``, or
``pip install 'climclusterpy-base[lmnn]'``); without it the script prints an install hint and
exits.

Provide a supervision signal
----------------------------

LMNN needs a per-cell class label aligned row by row with the features. For real data, the
label comes from :func:`~climclusterpy.compute_supervision` (see :doc:`supervision`). Here,
the example derives three latitude bands from the cell metadata:

.. code-block:: python

   import numpy as np

   lat = meta["latitude"].to_numpy()
   y = np.digitize(lat, np.quantile(lat, [1 / 3, 2 / 3]))   # 0/1/2, aligned to X rows

Learn a metric and cluster
--------------------------

With ``locally_weighted=True`` and the supervision labels, the package learns a distance and
then clusters under it. This example uses the global (linear) Mahalanobis metric, which is the
quickest to train:

.. code-block:: python

   from climclusterpy import cluster_matrix

   result = cluster_matrix(
       X, n_clusters=6, locally_weighted=True,
       supervision=y, standardize=True, lmnn_mode="global",
   )
   result.diagnostics       # LMNN training info

Without ``lmnn_mode``, the package uses the default ``"lowrank"``: a low-rank metric for every
cell, as in the paper. ``"diagonal"`` is the same trainer with a diagonal per-cell metric;
see :doc:`../explanation/methods`.
