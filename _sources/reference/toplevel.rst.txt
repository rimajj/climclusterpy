Data, timeseries, I/O & plotting
================================

The lower-level building blocks outside clustering and grid building: data loading and
the grid registry, per-cluster timeseries, file input/output, preprocessing and the
plotting helpers. Each is importable from its package (``climclusterpy.data``,
``climclusterpy.timeseries``, ...); the grid descriptions are also importable from
``climclusterpy`` itself. All of it runs on the core install, except the map plots, which
need the ``[viz]`` extra.

Data loading & the grid registry
---------------------------------

.. py:module:: climclusterpy.data

A :class:`~climclusterpy.data.DataRegistry` describes the original grid: its coordinates,
which cells exist (those with a soil code) and their ``cell_id``. You rarely build one
yourself — :func:`~climclusterpy.create_clusters` makes it and saves it as
``original_grid.nc`` in the output folder. When a function asks for one, use
:meth:`DataRegistry.load(path) <climclusterpy.data.DataRegistry.load>` on that file, or
:meth:`DataRegistry.from_soil_code(path) <climclusterpy.data.DataRegistry.from_soil_code>`
on the soil-code input the grid was built from; both give the same ``cell_id`` for every
cell.

Coordinates
-----------

Coordinates are rounded to 5 decimals and stored as 32-bit floats everywhere in the
package, so that the same cell always compares equal. Use these before joining your own
tables or datasets to the package's output.

Plotting
--------

.. py:module:: climclusterpy.viz

A deterministic, inch-based figure layout and the plots built on it. Only ``matplotlib``
is needed to import it; the map plots need ``cartopy`` (the ``[viz]`` extra). The layout
constants (margins, gutters, DPI, column widths) are importable from
``climclusterpy.viz.style`` for fine tuning but are not part of the public list.

Style and layout: ``StyleConfig``, ``apply_style``, ``style_context``, ``create_figure``,
``figure_size``, ``add_colorbar``, ``legend_below``, ``add_panel_label``,
``add_panel_labels``, ``save_figure``. Colours: ``OKABE_ITO``, ``TOL_BRIGHT``,
``TOL_VIBRANT``, ``qualitative_colors``, ``categorical_cmap``, ``get_cmap``,
``sequential_cmap``, ``diverging_cmap``. Maps: ``setup_map_ax``, ``scatter_on_map``,
``global_scatter_map``, ``categorical_scatter_map``, ``multi_panel_map``,
``comparison_map``. Plots: ``bar_chart``, ``boxplot_grid``, ``grouped_boxplot``,
``histogram``, ``metric_trend``, ``scatter_correlation``, ``eigenvalue_spectrum``,
``create_aggregated_visualizations``, ``create_comparison_plot``. Each docstring is its
reference: ``help(climclusterpy.viz.global_scatter_map)``.
