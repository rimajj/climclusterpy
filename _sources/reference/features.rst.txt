Feature engineering
===================

.. py:module:: climclusterpy.features

Transform loaded climate + soil data into the interpretable feature matrix that
clustering consumes: ecological summaries, then standardization / de-correlation / PCA
filtering. The mathematics behind each step is in
:doc:`../explanation/methods`.

.. note::

   :func:`~climclusterpy.features.summarize_climate_features` derives optional SPEI /
   potential-evapotranspiration drought diagnostics via the ``pyet`` package, which is
   not part of the core install: add the ``[features]`` extra (or ``[all]``) for it. The
   rest of the feature pipeline runs on the core install.
