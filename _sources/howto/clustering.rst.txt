Cluster a feature matrix (choose a mode)
========================================

:func:`~climclusterpy.cluster_matrix` turns a per-cell feature matrix into cluster labels.
It accepts either a NumPy array of shape ``(n_cells, n_features)`` or a
:class:`pandas.DataFrame` and returns a :class:`~climclusterpy.ClusterResult`. For a
DataFrame, the function splits off metadata columns such as ``cell_id``, ``latitude`` and
``longitude`` and carries them through. :doc:`features` describes the columns that
:func:`~climclusterpy.create_clusters` builds and how to build your own table.

Euclidean mode (no supervision)
-------------------------------

.. code-block:: python

   from climclusterpy import cluster_matrix

   result = cluster_matrix(X, n_clusters=7, locally_weighted=False, standardize=True)
   result.labels        # 1-indexed cluster label per cell, shape (n_cells,)
   result.linkage       # SciPy linkage matrix Z
   result.to_frame()    # DataFrame: metadata columns + a cluster_label column

Set ``standardize=True`` to z-score each feature before clustering. If your features are
already standardized, as the production feature pipeline does, leave it ``False`` (the
default) to avoid scaling twice. ``linkage_method`` sets the agglomeration rule (default
``"complete"``).

Pass a DataFrame
~~~~~~~~~~~~~~~~

.. code-block:: python

   # df has columns: cell_id, latitude, longitude, feat_1, feat_2, ...
   result = cluster_matrix(df, n_clusters=7)
   result.metadata          # the cell_id/latitude/longitude columns, row-aligned
   # Select feature columns explicitly if the automatic detection is not what you want:
   result = cluster_matrix(df, n_clusters=7, feature_columns=["feat_1", "feat_2"])

LMNN mode (supervised metric learning)
--------------------------------------

Before clustering, LMNN learns a distance metric from a supervision signal. The metric
pulls cells of the same class together and pushes cells of different classes apart. It
needs the ``[lmnn]`` extra (see :doc:`install`) and a supervision argument aligned
row by row with the features. The argument is either a
:class:`~climclusterpy.SupervisionResult` from :func:`~climclusterpy.compute_supervision`
(see :doc:`supervision`) or your own label array.

.. code-block:: python

   from climclusterpy import cluster_matrix, compute_supervision

   sup = compute_supervision("koppen_geiger", features_df=monthly_climatology)
   result = cluster_matrix(
       X,
       n_clusters=7,
       locally_weighted=True,
       supervision=sup,          # or an aligned 1-D label array
       lmnn_mode="lowrank",      # the default; or "diagonal" | "global"
       standardize=True,
   )
   result.diagnostics            # mode-specific LMNN training info

``lmnn_mode`` selects the LMNN mode:

* ``"lowrank"`` (default): a neural network predicts a low-rank Mahalanobis metric for
  every cell. The metric also captures how features interact, and it is the configuration
  of the published results. ``rank`` sets its rank (default 16, at most the number of
  features).
* ``"global"``: one linear Mahalanobis metric for all cells (``rank`` default: full rank).
* ``"diagonal"``: the same trainer with a diagonal metric. Every cell gets one weight per
  feature, so the features are rescaled but cannot interact. ``rank`` is refused.

``"local"`` and ``"enhanced"`` were removed in 0.6.0 and raise ``ValueError``. They trained a
different objective.

Every mode trains with ``torch``, and the two per-cell modes share one trainer and loss.
With ``seed`` (default 0), two identical calls give identical clusters, and ``seed=None``
draws afresh each time. Omitting ``supervision`` in LMNN mode raises a ``ValueError``.
:doc:`../explanation/methods` gives the mathematics of each mode.

Lower-level control
-------------------

To use a precomputed distance matrix, a custom linkage or a learned metric that you reuse,
call :func:`~climclusterpy.clustering.lmnn.run_lmnn_clustering` (it accepts
``return_distance_matrix=True``) or the primitives in :mod:`climclusterpy.clustering`
directly. The :doc:`../reference/clustering` lists them.
