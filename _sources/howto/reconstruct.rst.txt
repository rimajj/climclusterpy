Reconstruct the original grid
=============================

After you have run the model on the reduced grid, the package gives every original land cell
the output simulated for its group and writes the result as a NetCDF file on the original
grid. It matches cells by group label, not by coordinate, and runs on the base install.
:ref:`reconstruction-check` describes how to check the result.

The usual call
--------------

If you have the result of :func:`~climclusterpy.create_clusters`,
:func:`~climclusterpy.reconstruct_original_grid` needs nothing else:

.. code-block:: python

   from climclusterpy import create_clusters, reconstruct_original_grid

   clusters = create_clusters("/data/climate_input", n_clusters=2000,
                              output_dir="./clusters_2000")
   # ... run the vegetation model on clusters.netcdf_files ...
   full = reconstruct_original_grid("vegc.nc", clusters=clusters)
   full.path     # the reconstructed NetCDF (full.files when several inputs were given)

Restore a result in a later session
-----------------------------------

A model run can take days, so the session that called ``create_clusters`` has usually ended
when the output arrives. :func:`~climclusterpy.load_clusters` rebuilds the result from the
output folder, which holds everything needed (the mapping files, the labels and
``original_grid.nc``):

.. code-block:: python

   from climclusterpy import load_clusters, reconstruct_original_grid

   clusters = load_clusters("./clusters_2000")
   full = reconstruct_original_grid("vegc.nc", clusters=clusters)

   # the same in one step:
   full = reconstruct_original_grid("vegc.nc", clusters="./clusters_2000")

You can move or copy the folder to another machine as a whole, because the paths in its run
record are relative to it. A folder written by a version before 0.3.0 has no run record. For
such a folder, use the explicit call below.

Without a result object
-----------------------

Instead, you can give :func:`~climclusterpy.reconstruct_original_grid` the mapping CSVs and a
:class:`~climclusterpy.data.DataRegistry` that describes the original grid. Load the registry
from the saved grid file, or rebuild it from the same soil-code file that built the reduced
grid, which gives every cell the same ``cell_id``:

.. code-block:: python

   from climclusterpy import DataRegistry, reconstruct_original_grid

   registry = DataRegistry.load("clusters_67/original_grid.nc")
   # or rebuild it from what defined the cells, e.g. DataRegistry.from_mask("land.nc"),
   # DataRegistry.from_cell_list("gridlist.csv") or DataRegistry.from_soil_code("soil_code.nc")

   out_path = reconstruct_original_grid(
       "vegc_clustered.nc",             # output simulated on the cluster grid
       registry=registry,
       id_mapping_csv="clusters_67/cluster_id_mapping_67.csv",
       compact_map_csv="clusters_67/cluster_compact_map_67.csv",
       output_dir="reconstructed",
   ).path

Mapping files
-------------

:func:`~climclusterpy.create_clusters` writes both files into the output folder, using
:func:`~climclusterpy.grid.build_reduced_grid` underneath:

``id_mapping_csv``: ``cluster_id_mapping_{K}.csv``
   One row per original (valid) cell: ``original_cell_id``, ``new_cell_id``,
   ``cluster_index``, ``cluster_label``.

``compact_map_csv``: ``cluster_compact_map_{K}.csv``
   Maps each group to its position on the reduced grid: ``cluster_label``, ``lat_index``
   (its latitude row), ``cluster_index_start`` and ``cluster_index_end`` (its first and last
   column in that row). Several groups can share a row.

Reconstruction paths
--------------------

``"output"`` (default)
   One simulated cell per group: model output (dims ``lat``/``lon``, as LPJmL writes
   them) or a reduced-grid NetCDF that this package wrote (dims ``latitude``/``longitude``).
   The path reconstructs all spatial variables.
   → :func:`~climclusterpy.grid.reconstruct_output_netcdf`.

``"distributed"``
   Output of a ``cell_selection="distributed"`` grid (several cells per group). Also pass
   ``distributed_mapping_csv`` and ``labels_csv``, and optionally ``aggregate="median"``.
   :func:`~climclusterpy.reconstruct_original_grid` picks this path, and both files, from the
   ``create_clusters`` result on its own (see :doc:`cell_selection`).
   → :func:`~climclusterpy.grid.reconstruct_from_distributed`.

Checking the result
-------------------

:func:`~climclusterpy.grid.validate_reconstruction_grid` checks that the reconstructed
grid matches the original grid and that cells that are not land stay ``NaN``. ``registry`` is the
:class:`~climclusterpy.data.DataRegistry` from above, or ``clusters.registry``:

.. code-block:: python

   from climclusterpy.grid import validate_reconstruction_grid

   assert validate_reconstruction_grid(out_path, registry, var_name="vegc")
