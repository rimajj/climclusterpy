climclusterpy
=============

.. image:: _static/logo-wordmark.svg
   :alt: climclusterpy
   :width: 420px

**Ecologically informed clustering of climate and static fields for reduced model grids.**

``climclusterpy`` divides the cells of a model's grid into groups of similar climate and
static fields (soil, elevation, land cover, ...). You run the model on one or a few cells of
each group, which the package writes as a *reduced grid*, and every original cell then
receives the output simulated for its group. The input is any set of gridded climate fields
and static fields, under the names the model uses. The accompanying paper describes the method.

Two calls cover the whole workflow:

.. code-block:: python

   from climclusterpy import create_clusters, reconstruct_original_grid

   # 1. Reduce the grid: writes model-ready NetCDFs and the mapping CSVs.
   clusters = create_clusters(
       climate={"temperature": "/data/tas.nc", "precipitation": "/data/pr.nc"},
       static={"soil": ("/data/soil.nc", "categorical")},
       n_clusters=2000,
   )

   # ... run the model on clusters.netcdf_files ...

   # 2. Give every original cell the output simulated for its group.
   full = reconstruct_original_grid("vegc_output.nc", clusters=clusters)

With ``locally_weighted=True``, the package learns the distance between cells before
clustering. Köppen–Geiger classes computed from the climate input, an ecoregion map or the
model's own output traits can supervise the learned distance. The following call uses output traits:

.. code-block:: python

   clusters = create_clusters(
       climate={"temperature": "/data/tas.nc", "precipitation": "/data/pr.nc"},
       n_clusters=2000,
       locally_weighted=True,
       supervision_data="/data/model_output/trait_grids",   # or a per-cell CSV
       supervision=["sla", "wooddens", "height", "biomass"],
   )

You can also build the input beforehand as a :class:`~climclusterpy.GenericInputs`. The
package accepts the six-file input layout of LPJmL-FIT, the model it was developed with, as
a directory (:doc:`howto/inputs`). :func:`~climclusterpy.load_clusters` restores the result
of ``create_clusters`` in a later session (:doc:`howto/reconstruct`).

The individual steps are also available as functions, for example
:func:`~climclusterpy.cluster_matrix` and :func:`~climclusterpy.compute_supervision`
(:doc:`reference/index`). Only the features that need heavy dependencies load them
(:doc:`howto/install`).
